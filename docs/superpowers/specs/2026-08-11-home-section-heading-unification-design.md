# Home Section Heading Unification

## Approved visual contract

- Apply one typography system to the five homepage section titles: “Human taste. Machine possibility.”, “Artists shaping new realities.”, “Selected work, made to move.”, “Built with brands. Made for culture.”, and “We build the whole world.”
- Use DM Sans Medium (`font-weight: 500`) with `letter-spacing: 0em`.
- Use the same responsive font size and line-height for all five titles.
- Preserve the existing authored line breaks.
- Do not change the homepage hero, body copy, navigation, profile pages, media, or layout.

## Success criteria

All five titles resolve to the same font family, weight, tracking, responsive size, and line-height on desktop and mobile without overflow.
